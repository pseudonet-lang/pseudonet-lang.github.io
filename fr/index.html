Écrivez votre pseudocode avec vos mots.
Obtenez un programme qui tourne.

Pseudo.NET compile du pseudocode libre en C# grâce à un modèle de langage local. Aucune syntaxe imposée, pas de compte, pas de clé d'API. Rien ne quitte votre machine.

Télécharger Code source

Deux types de projet

PseudoCode

Applications console. Algorithmique, exercices, enseignement.

PseudrawCode

Fenêtres avec dessin, clavier et minuterie. Petits jeux et animations.

Six exemples prêts à lancer sont fournis comme modèles de projet : Snake, Tetris, balle rebondissante, nombres premiers, tri à bulles, devine le nombre. Le premier lancement n'exige pas Ollama.

Pour les enseignants

Les agents écrivent du code, mais les élèves doivent toujours apprendre à raisonner algorithmiquement. Le pseudocode est la méthode classique pour l'enseigner, mais il n'a jamais été exécutable. Avec Pseudo.NET, le pseudocode d'un élève s'exécute tel qu'il l'a écrit, dans sa langue et son style, et le C# généré est un vrai programme à lire ensuite.

  • Confidentiel : le modèle tourne en local, aucune donnée d'élève n'est envoyée.
  • Gratuit : licence MIT, sans compte ni abonnement.
  • Aucune syntaxe à retenir : accolades, indentation seule ou phrases, tout fonctionne.

Le pseudocode dans votre langue

Français, anglais, espagnol, allemand, italien, portugais, chinois, japonais, russe… Les noms de couleurs et de touches ont des tables JSON par langue, et les messages du compilateur sont localisés. Ajouter la vôtre revient à écrire un fichier.

nombresPremiers = une nouvelle liste

définir est-ce que compteur est premier, qui retourne un booléen
	estPremier = vrai
	si compteur est inférieur à 2 alors
		estPremier = faux
	répéter diviseur de 2 à 50
		si diviseur est inférieur à compteur alors
			reste = compteur modulo diviseur
			si reste est égal à 0 alors
				estPremier = faux
	retourner estPremier

répéter compteur de 2 à 50
	premier = est-ce que compteur est premier
	si premier alors
		ajouter compteur à nombresPremiers

afficher le texte "Nombres premiers jusqu'à 50 :"
pour chaque nombre dans nombresPremiers
	afficher nombre

Installation

Deux façons, même résultat. Dans les deux cas, Ollama est nécessaire pour vos propres programmes, puis une fois : ollama pull qwen2.5-coder:7b (environ 5 Go). Les exemples tournent sans.

En ligne de commande (n'importe quel éditeur)

Nécessite le SDK .NET 8 ou plus. Les modèles Pseudraw (fenêtre) exigent Windows.

dotnet new install PseudoNet.Templates
dotnet new pseudocode -n Bonjour
cd Bonjour
dotnet run

Essayer un jeu tout fait (sans Ollama pour les exemples) :

dotnet new pseudo-tetris -n MonTetris
cd MonTetris
dotnet run

Autres modèles : pseudrawcode, pseudo-snake, pseudo-bounce, pseudo-primes, pseudo-bubble-sort, pseudo-guess-number. Modifiez ensuite Program.pseudo dans l'éditeur de votre choix et relancez.

Dans Visual Studio

  1. Visual Studio 2026 (Community suffit ; 2022 visé mais non testé).
  2. Téléchargez le .vsix depuis les releases et ouvrez-le.
  3. Fichier → Nouveau → Projet → cherchez « Pseudo ». F5.

Limites assumées

Un modèle local de 7 milliards de paramètres est bon, pas parfait : un programme très long ou ambigu peut demander une reformulation. Windows uniquement pour l'instant (Visual Studio, ou le SDK .NET en ligne de commande).

Soutenir
